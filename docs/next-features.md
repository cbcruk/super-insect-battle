# 다음 기능 후보 목록

> 현재 상태: 24종 절지동물, 51개 행동, 6개 상태이상, 4가지 환경, AI 대전 모드, 리플레이 시스템, 밸런스 조정 완료 (승률 19%~79%)

---

## 1. 게임플레이 확장

### 1-1. 토너먼트 모드

- 8강/4강/결승 싱글 엘리미네이션 브라켓
- 플레이어가 1캐릭 선택 후 AI 토너먼트 진행
- 또는 24종 전체 자동 토너먼트
- 결과 화면에 대진표 트리 표시
- **난이도**: 중간 — 새 UI 화면 + 대전 스케줄링 로직 필요

### 1-2. 3판 2선승제

- 동일 상대와 3전 진행, 2승 먼저 달성 시 승리
- 각 라운드 사이 환경 변경
- 시리즈 전적 표시
- **난이도**: 낮음 — 기존 배틀 로직 래핑

### 1-3. 팀 배틀 (3 vs 3)

- 각 플레이어가 3마리 선택, 순서대로 출전
- 한 마리가 쓰러지면 다음 마리 자동 교체
- HP는 라운드간 유지 (체력 관리 전략)
- **난이도**: 높음 — 배틀 엔진 구조 변경 필요

### 1-4. 랜덤 매치

- 양쪽 모두 랜덤 절지동물 배정
- 환경도 랜덤
- 빠른 플레이를 위한 원버튼 모드
- **난이도**: 낮음 — 기존 로직 조합

## 2. 콘텐츠 추가

### 2-1. 새 절지동물 추가 (8~12종)

후보:

- **무당벌레** (ladybug) — defensive, 비행, 화학방어
- **잠자리** (dragonfly) — striker, 고속, 높은 회피
- **개미** (ant) — grappler, 저체중 고힘
- **사슴벌레 (미야마)** (miyama_stag_beetle) — grappler, 장수풍뎅이급
- **꽃무지** (flower_chafer) — defensive, 비행
- **물방개** (diving_beetle) — striker, 수중 특화
- **하늘소** (longhorn_beetle) — grappler, 긴 더듬이
- **벼메뚜기** (rice_grasshopper) — striker, 점프 특화
- **거저리** (darkling_beetle) — defensive, 화학방어
- **집게벌레 (큰)** (giant_earwig) — striker, 집게 강화
- **반딧불이** (firefly) — venomous, 야행성 특화
- **노린재 (초록)** (green_stink_bug) — venomous, 화학방어
- **난이도**: 중간 — YAML 데이터 작성 + 밸런스 조정

### 2-2. 새 행동(액션) 추가

후보:

- **비행 돌진** (aerial_dive) — 비행 가능 종 전용, 고위력 고쿨다운
- **독안개** (toxic_cloud) — 범위 독, venomous 전용
- **굴파기** (burrow) — 1턴 잠복 후 다음 턴 기습 (높은 크리티컬)
- **탈피** (molt) — 상태이상 해제 + HP 소량 회복, 높은 쿨다운
- **위협 포즈** (threat_display) — 상대 공격력 디버프
- **자폭** (self_destruct) — 자기 HP 절반 소모 + 대데미지
- **난이도**: 중간 — 일부는 새로운 메카닉 필요

### 2-3. 새 상태이상 추가

후보:

- **동상** (freeze) — 1턴 행동 불가, 물리 피해 1.5배
- **출혈** (bleed) — 매 턴 공격 시 추가 피해
- **속도 저하** (slow) — 우선도 -1 페널티
- **난이도**: 낮음 — 기존 상태이상 시스템 확장

### 2-4. 새 환경 추가

후보:

- **도시** (urban) — 바퀴벌레, 개미 등 도시 적응종 보너스
- **산악** (mountain) — 고지대 종 보너스
- **해안** (coast) — 물가 종 보너스
- **지하** (underground) — 땅속 종 보너스
- **난이도**: 낮음 — 환경 데이터 + 서식지 매핑

## 3. 시스템 기능

### 3-1. 리플레이 뷰어

- 저장된 리플레이 파일 불러오기
- 턴 단위 재생 (앞/뒤 이동 가능)
- 배틀 로그 + HP 변화 시각화
- 메인 메뉴에 "리플레이 보기" 항목 추가
- **난이도**: 중간 — 리플레이 디코딩 + 새 UI 화면

### 3-2. 전적 기록 시스템 (로컬)

- 대전 모드 결과를 로컬 파일에 자동 저장
- 플레이어 통산 전적 표시
- 가장 많이 사용한 절지동물, 최다 연승 등 통계
- 메인 메뉴에 "내 전적" 항목 추가
- **난이도**: 중간 — 로컬 파일 I/O + 통계 집계

### 3-3. 절지동물 비교 화면

- 두 절지동물을 나란히 비교
- 스탯 레이더 차트 (텍스트 기반)
- 상성, 환경 보너스 비교
- 도감에서 "비교" 기능 추가
- **난이도**: 낮음 — UI 컴포넌트 추가

### 3-4. 배틀 분석 리포트

- 배틀 종료 후 상세 분석 표시
- 총 데미지 합계, 크리티컬 횟수, 회피 횟수
- 가장 효과적이었던 행동
- 턴별 HP 변화 그래프 (텍스트)
- **난이도**: 낮음 — 기존 로그 데이터 집계

---

## 4. 진화/성장 시스템

### 4-1. 경험치 & 레벨

- 대전 승리 시 경험치 획득
- 레벨업 시 HP, 공격력 소폭 상승
- 최대 레벨 제한 (예: 10)
- **난이도**: 높음 — 저장 시스템 + 밸런스 재설계

### 4-2. 스킬 해금

- 레벨업 시 새로운 행동 해금
- 최대 4~5개 행동 장착 (슬롯 제한)
- 커스텀 행동 세트 구성
- **난이도**: 높음 — 행동 관리 UI + 저장 시스템

### 4-3. 아이템/장비

- 1회용 소모품: 체력 회복, 상태이상 치료
- 장비: 공격력/방어력 보정 아이템
- 배틀 전 아이템 장착
- **난이도**: 높음 — 새 데이터 모델 + UI + 배틀 로직

## 5. UI/UX 개선

### 5-1. 사운드 이펙트

- 웹 버전에서 효과음 추가
- 공격, 크리티컬, 회피, 상태이상 등
- BGM 옵션
- **난이도**: 중간 — 웹 전용, 오디오 에셋 필요

### 5-2. 애니메이션 강화 (웹)

- 절지동물 아스키 아트 또는 이미지
- 공격/방어 모션
- 데미지 수치 팝업
- **난이도**: 높음 — 비주얼 에셋 + 애니메이션 시스템

### 5-3. 다국어 지원

- 현재 한국어 중심 UI
- 영어/일본어 지원 추가
- i18n 시스템 도입
- **난이도**: 중간 — 문자열 추출 + 번역

## 6. 멀티플레이어

### 6-1. 로컬 2인 대전

- 한 터미널에서 교대 입력
- 행동 선택 시 상대에게 화면 가리기
- **난이도**: 중간 — 플레이어 2 입력 처리

### 6-2. 온라인 PvP

- WebSocket 기반 실시간 대전
- 매칭 시스템 (랜덤 또는 초대)
- 서버에서 배틀 진행, 클라이언트는 뷰어
- **난이도**: 매우 높음 — 네트워크 + 동기화 + 매칭
